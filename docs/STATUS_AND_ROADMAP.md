## Measurement plan

| Metric | How to interpret |
| --- | --- |
| Owner acceptance rate | Accepted qualified leads / qualified leads reviewed, with dates and counts. |
| Paid research cost per qualified lead | Recorded paid research/API cost / qualified leads; undefined if none qualify. |
| Positive reply rate | Positive replies / delivered approved initial emails, with observation window. |
| Lead-to-win rate | Won customers / evaluated lead cohort after a defined maturity window. |
| Full acquisition cost | Include relevant labor, tools and outreach costs when known; do not substitute API spend alone. |
| Attributable revenue | Recorded deal revenue tied to CRM provenance; no estimate labeled as collected revenue. |
| Control reliability | Verify pause, budget, suppression and approval behavior using meaningful scenarios. |

## Present limitations

No production research run, prospect dataset, customer count, conversion result or revenue return is established. Source access and tooling are conditional on later integration. Public capacity proxies are imperfect, crawl coverage is bounded and automated review is not a comprehensive security or accessibility certification.
